# i3 adapter

The i3 adapter is i3's own `complete-run.pl`, unchanged, using Xvfb and Xephyr.
The runner checks that both its source and binary are from the vendored suite's
pinned commit before invoking it. I3-derived replay feeds the captured fake
output mode, position, and primary marker back through i3's native
`fake-outputs` directive; affected rows carry
`adapted = ["source-fake-output-layout"]`.
